Trafficity Mod Manager API Documentation

Trafficity Mod Manager injects a pre-bundle loader (/mods-runtime/loader.js) into dist/index.html and mounts local mod endpoints inside Trafficity's Electron static server. Mods are plain ES modules and CSS files stored in AppData/Roaming/Trafficity/mods/ (next to player saves, preserved across Steam updates) with no build step required.

In-Game Controls: Press F9 or click the bottom-right Mods pill to open the Mod Manager drawer, toggle mods, open or copy the mods folder path, and reload the game.

Mod Format (mod.json)

Each mod lives in its own directory under mods/<folder>/ containing a mod.json manifest, an optional ES module entry file, and optional stylesheets or assets. 

{
  "id": "my-mod",
  "name": "My Trafficity Mod",
  "version": "1.0.0",
  "author": "Author Name",
  "description": "Short summary shown in the F9 Mod Manager drawer.",
  "dependencies": [],
  "optionalDependencies": ["redo-mod"],
  "entry": "mod.js",
  "styles": ["style.css"]
}
Field Type Description
id string Unique mod identifier. Defaults to the folder name if omitted.
name string Display name in the Mod Manager UI.
version string Version string displayed next to the name. Defaults to "1.0.0".
author string Optional author name.
description string Optional description shown in the drawer.
entry string | null Relative path to the ES module script (e.g. "mod.js"), loaded via await import(...).
styles string[] Relative paths to CSS files injected as <link rel="stylesheet"> tags.
dependencies string[] Required mod IDs. Loaded before this mod; if missing or disabled, this mod is skipped with a warning in the drawer.
optionalDependencies string[] Optional mod IDs. If enabled, guaranteed to load before this mod; if absent, this mod still loads.

Dependencies & Inter-Mod Services

The loader performs a topological sort across all enabled mods using dependencies and optionalDependencies, then imports each mod sequentially via await import(...). A provider mod registers its service at module top-level with TrafficityMods.provide(name, api), and consumer mods retrieve it with TrafficityMods.use(name). 

// Provider mod (e.g. redo-mod/mod.js)
const mods = window.TrafficityMods;
mods.provide("redo", { redo, canRedo, clear });

// Consumer mod (declares optionalDependencies: ["redo-mod"])
const mods = window.TrafficityMods;
mods.use("redo")?.redo();

Core API: window.TrafficityMods

Registered synchronously before Trafficity's main bundle executes.

TrafficityMods.version string

Current loader API version ("1.3.0").

TrafficityMods.bindKey(combo, handler)

Registers a capture-phase keydown binding on window, automatically skipping <input>, <textarea>, <select>, and contentEditable targets, as well as synthetic events dispatched by mods.

  • combo: Key string with optional modifiers (e.g. "q", "1", "Alt+1", "Ctrl+y", "Shift+Delete", "BracketLeft").
  • handler(event): If the handler returns false, the event is allowed to propagate to Trafficity natively. Any other return value calls preventDefault() and stopImmediatePropagation().
TrafficityMods.onMouse(type, handler, options?)

Registers a capture-phase mouse or wheel listener on window ("mousedown", "mousemove", "mouseup", "click", "contextmenu", "wheel"). Events marked with the internal synthetic flag are automatically ignored to prevent recursion. Pass { passive: false } when calling preventDefault() inside a "wheel" handler.

TrafficityMods.sendSyntheticKey(code, key?, keyCode?, modifiers?)

Dispatches a synthetic keydown KeyboardEvent onto window that bypasses mod listeners and goes directly to Trafficity. modifiers accepts { ctrlKey, shiftKey, altKey, metaKey }.

TrafficityMods.provide(name, serviceApi) / TrafficityMods.use(name)

Registers or retrieves a named service object for inter-mod communication. Returns null if not registered.

TrafficityMods.getConfig(modId, defaults?) / await TrafficityMods.setConfig(modId, data)

Reads or persists configuration for modId in its in-folder settings.toml (if present) or AppData/Roaming/Trafficity/mods-config.json via POST /api/mods/config, merged over optional defaults.

TrafficityMods.defineMod(setupMod) / export default function(modApi, game)

Optional ES module entrypoint pattern: if a mod's entry exports a default function, the loader invokes it automatically with (TrafficityMods, TrafficityMods.game).

TrafficityMods.addOverlay(id, htmlOrNode)

Mounts or updates a persistent <div id="tmod-overlay-<id>"> element in document.body.

TrafficityMods.getMods() / TrafficityMods.getModsDir()

Returns a shallow copy of the discovered mod manifest list and the resolved mods directory path.

TrafficityMods.buildings.register(configOrInstance)

Registers a custom building type (CustomBuilding) into Trafficity's main-thread building/simulation/UI modules and isolated Web Workers, with support for procedural 2.5D getExtrusions, quotas, and onPlace/onDelete/onSelect/onRenderWorld hooks. Also exposes CustomBuilding, get(type), and list().

High-level helpers abstracting Trafficity's React toolbar DOM, world coordinates, audio, input events, and internal Parcel modules.

Custom Buildings: window.TrafficityMods.buildings

Registers new building types across Trafficity's main-thread Parcel modules and isolated simulation Web Workers (car-worker, happiness-worker, pathfinding-worker). Call register() during mod setup before a map loads so worker hooks inject cleanly.

Member Returns Behavior
buildings.CustomBuilding Class Validated class wrapping a custom building definition, toWorkerSafeDefinition(), toMainDefinition(), getDisplayName(lang), and getTotalVehicleCount().
buildings.register(configOrInstance) TrafficityCustomBuilding Validates and registers a CustomBuilding into main-thread building/UI/simulation tables and worker shims.
buildings.get(type) TrafficityCustomBuilding | null Returns the registered custom building matching type, or null.
buildings.list() TrafficityCustomBuilding[] Returns an array of all registered custom buildings.

Extending the Facade

Shared library mods can attach new domain helpers directly onto TrafficityMods.game using TrafficityMods.extendGame(methods) so dependent mods can call them cleanly: 

// Inside a shared library mod
window.TrafficityMods.extendGame({
  worldToScreen(wx, wy) {
    const cam = this.getCameraState();
    if (!cam) return null;
    return { x: wx * cam.zoom + cam.x, y: wy * cam.zoom + cam.y };
  },
});

HTTP Endpoints & Desktop IPC Bridge

All mod endpoints are served by Trafficity's local HTTP server (http://127.0.0.1:<port>) with Cross-Origin-Opener-Policy: same-origin, Cross-Origin-Embedder-Policy: require-corp, and Cross-Origin-Resource-Policy: same-origin headers.

Endpoint / Bridge Description
GET /api/mods[?enabled=1] Returns { modsDir, gameRelease, mods } discovered from mods/*/mod.json.
POST /api/mods/toggle Body: { id, enabled }. Persists toggle state in mods-config.json.
POST /api/mods/config Body: { id, config }. Persists per-mod configuration in mods-config.json.
GET /mods-runtime/loader.js Serves the pre-bundle mod loader and in-game Mod Manager UI.
GET /mods-runtime/mods/<folder>/<file> Serves mod scripts, CSS, and assets with path-traversal protection.
window.trafficityDesktop.openModsFolder() IPC invoke to open-mods-folder. Opens native Explorer on real Windows; under Proton/Wine returns { ok: false, wine: true, modsDir, hostPath } instead of invoking shell.openPath.
window.trafficityDesktop.reloadGame() IPC send to reload-game, calling webContents.reloadIgnoringCache().

Game Targets, Events & Layering Reference

  • Toolbar data-tutorial-target values: "grid", "traffic-lights", "roundabout", "keep-clear", "rectangle-delete", "traffic-eraser", "road-type", "buildings", "unlock-tiles".
  • Lifecycle event: trafficity:undo-ready is dispatched on window via queueMicrotask right after f5Ojv finishes initializing (avoiding Parcel TDZ errors).
  • Snap tuning globals (used by snap-perf-fix): globalThis.__trafficityMaxSnapSearchSteps (default 30), globalThis.__trafficitySnapSearchStride (default 1), and globalThis.__trafficitySuppressSnapLog (boolean).
  • Canvas overlay layering: Append world-aligned <canvas> elements inside document.getElementById("pixi") with pointer-events: none so they draw above the map and beneath all React UI controls.

Developing & Testing Mods

Every mod folder can include a self-contained mod.test.mjs using Node's built-in node:test and node:assert/strict modules with zero external dependencies. 

# Test a single mod directly in its own directory
cd examples/toolbelt-hotkeys-mod
node --test

# Run the full repository test suite (patcher + mod-api + all example mods)
cd ~/code/trafficity-mod-manager
npm test

# Patch or restore Trafficity's resources/app.asar
npm run patch
npm run restore
